- 统一修复长工具结果的硬截断：先保存完整原始返回，再给 Agent 有明确范围和续读位置的预览。覆盖 PDF 阅读、论文检索、图片描述和外部工具等。
- 新增当前会话的结果目录、原文分页读取和原文关键词搜索；上下文压缩或应用重启后，仍能取回结果末尾。
- 历史压缩保留结果引用，并保护当前请求和最近一组工具结果，避免工具刚返回的证据又被缩成 800 字符。
- 保存与读取受会话、来源工具和研究范围约束；记录纳入现有备份与会话删除流程。保存失败明确报告，不自动重复已执行的操作。
- 证据卡保留续读引用；核验会区分完整工具返回、当前可见片段和原始 PDF 的覆盖范围。旧版本已经截断且未保存的尾部需要重新读取来源。
- 增加跨限长、压缩、重启、Unicode 字符位置、末尾搜索、权限隔离和删除的回归测试，并通过真实长 PDF 的桌面重启验证。
