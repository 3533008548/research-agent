- 核验修正现在输出一份完整答复并替换初稿，重新打开会话不会再并列显示初稿、核对过程和修正稿。
- 非阻断核验意见保留为运行状态，不再直接附加到回复；旧版自动附加的核验提示不再传给后续对话模型。
- 当前轮核验只使用当前用户请求之后的工具结果，不再因上一轮工具调用触发核验。
- PDF 阅读器增加局部错误恢复界面；加载失败时保留工作台与其他标签页，并显示错误详情。
- 页面入口禁用缓存，避免更新后引用旧阅读器资源；桌面端将捕获的界面异常保存到本机 renderer.log，便于定位。

本次公开发行同时包含此前本地版本的应用内更新、PDF 路径与 OCR 入库修复，以及关系审查移除。

0.2.2 客户端可在「设置 → 通用 → 应用更新」检查并安装本版本。0.2.1 及更早版本需要手动安装一次，之后可使用应用内更新。更新保留论文、笔记和配置。
